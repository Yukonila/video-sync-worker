# Video Sync

一个 Chrome 扩展，让两台（或更多）设备远程同步视频播放。在一台设备上播放、暂停、拖动进度条，另一台设备会自动跟随。

适用于：和朋友远程一起看电影、和家人同步追剧、跨设备（Windows / Linux / macOS）同步播放进度。

---

## 工作原理

- 每台设备安装同一个 Chrome 扩展
- 所有设备连接到同一个 WebSocket 服务器（默认使用项目作者部署的公共服务器）
- 输入相同的**房间号**即可进入同一房间
- 房间内任何一方的播放 / 暂停 / 进度操作，都会实时广播给房间内其他人

服务器只转发「播放 / 暂停 / 进度」这类指令，**不传输任何视频内容，也不记录你在看什么**。

## 安装

### 从 GitHub 安装（推荐）

1. 下载本仓库的 ZIP 并解压，或 `git clone` 到本地
2. 打开 Chrome，地址栏输入 `chrome://extensions`
3. 打开右上角的 **开发者模式**
4. 点击 **加载已解压的扩展程序**
5. 选择解压出来的 `extension` 文件夹
6. 扩展图标会出现在浏览器工具栏

> 需要 Chrome 116 或更高版本。

## 使用

### 1. 两台设备都安装扩展

在你的两台设备上分别完成上面的安装步骤。

### 2. 建立房间

在其中一台设备上：

1. 点击浏览器工具栏的 **Video Sync** 图标
2. 点击 **生成随机房间号**，得到一个类似 `a3f9c2d1` 的房间号
3. 点击 **连接**，状态变为「已连接」
4. 把这个房间号发给另一台设备的使用者

### 3. 另一台设备加入

在另一台设备上：

1. 点击扩展图标
2. 在**房间号**输入框填入刚才拿到的房间号
3. 点击 **连接**

两台设备现在处于同一房间。

### 4. 同步播放

1. 两台设备**手动打开同一个视频链接**（例如同一个 YouTube 视频）
2. 在任意一台设备上点击播放，另一台会自动跟随
3. 暂停、拖动进度条同样会同步

> **注意**：扩展只同步播放状态，不会自动帮对方打开视频页面。两台设备需要先打开同一个视频链接，再通过房间号同步。

## 用户设置

点击扩展图标后，可以在弹窗里配置以下内容。

### 服务器地址

- **留空**：使用项目作者提供的公共服务器（默认）
- **填写自定义地址**：使用你自己的服务器，格式为 `wss://你的域名/ws`

如果你有隐私顾虑，或者公共服务器不可用，可以按下方「自建服务器」章节部署自己的服务器，然后把地址填到这里。

### 房间号

- 房间号是进入同一房间的凭证，**知道房间号的人都能加入**
- 房间号由创建者生成，建议使用 **生成随机房间号** 按钮，避免与他人撞车
- 所有使用公共服务器的用户共享同一个服务器，随机房间号能有效避免串房

### 连接状态

- **已连接**：WebSocket 连接正常，可以同步
- **未连接 / 连接失败**：检查网络、服务器地址是否正确；公共服务器首次使用可能有几分钟的证书生效时间

---

## 已知限制

- **仅同步播放状态**，不传输视频内容。两台设备需自行打开同一个视频链接
- 视频同步依赖浏览器对 `<video>` 元素的控制，部分使用加密播放（DRM）或特殊播放器的网站可能无法同步
- 公共服务器为免费额度，**首次操作可能有 1–2 秒延迟**（服务器休眠唤醒导致），之后恢复正常
- 房间号是唯一凭证，没有密码机制。**不要把房间号公开分享**

## 自建服务器（可选）

如果你不想依赖公共服务器，可以部署自己的 Cloudflare Worker。整个过程免费，不需要买服务器。

### 前置要求

- Cloudflare 账号（免费）
- Node.js 16.17.0 或更高

### 部署步骤

```bash
# 1. 克隆仓库
git clone <你的仓库地址>
cd video-sync-worker

# 2. 安装依赖
npm install

# 3. 登录 Cloudflare
npx wrangler login

# 4. 部署
npx wrangler deploy
```

部署成功后会输出你的 Worker 地址，例如：

```
https://video-sync-worker.你的子域.workers.dev
```

对应的 WebSocket 地址为：

```
wss://video-sync-worker.你的子域.workers.dev/ws
```

把 `wss://.../ws` 填入扩展的「服务器地址」输入框即可。

### 修改扩展默认服务器（可选）

如果你希望别人下载你的扩展后默认就连你的服务器，可以修改两个文件里的默认地址：

- `extension/background.js` 的 `DEFAULT_SERVER`
- `extension/popup.js` 的 `DEFAULT_SERVER`

## 常见问题

**Q：为什么两台设备延迟有点大？**

公共服务器使用 Cloudflare Durable Object 的休眠机制，房间空闲时会休眠，第一条操作消息需要唤醒服务器，可能有 1–2 秒延迟。后续操作恢复正常。如果不接受这个延迟，可以自建服务器并关闭休眠。

**Q：为什么对方打开了视频但我这边没自动打开？**

扩展不传输视频 URL，只同步播放状态。两台设备需要手动打开同一个视频链接。

**Q：暂停 / 播放有时候不同步？**

确保两台设备打开的是**同一个视频**，并且扩展显示「已连接」。部分网站的播放器会拦截扩展的控制，导致同步失败。

**Q：房间号会泄露我在看什么吗？**

不会。服务器只转发播放 / 暂停 / 进度指令，无法知道视频内容或标题。

**Q：公共服务器安全吗？**

所有通信使用 `wss://` 加密。但房间号是唯一凭证，知道房间号的人可以加入并看到播放状态。不要把房间号公开分享。

## 技术栈

- **Chrome 扩展**：Manifest V3，Service Worker + Content Script
- **服务器**：Cloudflare Workers + Durable Objects
- **通信**：WebSocket（`wss://`）
